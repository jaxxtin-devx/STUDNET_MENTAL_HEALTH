# 🧠 Student Mental Health Prediction using Machine Learning

## 📌 Overview

Mental health issues among students have become increasingly common due to academic pressure, financial stress, workload, and lifestyle changes. Early identification of students at risk can help institutions provide timely support and improve overall well-being.

This project builds a Machine Learning model that predicts whether a student is likely to experience depression based on various academic, financial, and personal factors.

The project follows a complete end-to-end Machine Learning pipeline—from data preprocessing and exploratory data analysis to model training, evaluation, optimization, and deployment preparation.

---

# 🎯 Problem Statement

Develop a predictive machine learning system capable of identifying students who may be experiencing depression using survey-based data.

The objective is **not to diagnose depression**, but to provide an early risk assessment that can assist educators and mental health professionals.

# 🤖 Models Trained

The following machine learning algorithms were evaluated:

* Logistic Regression
* Decision Tree
* Random Forest
* Support Vector Machine (SVM)
* K-Nearest Neighbors (KNN)
* Naive Bayes
* XGBoost

After comparison, **XGBoost** achieved the best overall performance and was selected as the final model.

---

# 📈 Model Performance

### Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
* ROC Curve
* ROC-AUC Score

### Final ROC-AUC Score

**0.9195**

A ROC-AUC score of **0.9195** indicates excellent discrimination between students at risk of depression and those not at risk.
